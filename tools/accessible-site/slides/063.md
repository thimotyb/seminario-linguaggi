### Confronto tra i quattro cloud

Tabella con i criteri sulle righe e i provider sulle colonne (AWS, Azure, Google, OCI = Oracle Cloud Infrastructure):

| Criterio | AWS | Azure | Google | OCI |
|---|---|---|---|---|
| Fit ricorrente | ecosistema ampio | Microsoft + hybrid | data · AI · K8s | Oracle workload |
| Differenziatore | maturità operativa | identity/enterprise | analytics/cloud-native | DB + multicloud |
| Verificare | complessità/costi | licenze e governance | skill e copertura | fit fuori stack Oracle |
| Prima domanda | servizi già usati? | Microsoft è centrale? | dati/AI dominano? | DB Oracle è centrale? |

**Decisione:** skill disponibili · data gravity · compliance/region · servizi gestiti · TCO/egress · exit strategy.
