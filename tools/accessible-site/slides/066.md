# sostituisci
### Schema: la catena di tracciabilità in sei passi

Sei riquadri numerati in sequenza da sinistra a destra, collegati da frecce:

1. **Bisogno**: Epic e Feature.
2. **Lavoro**: Story e Task.
3. **Codice**: Git e pull request (PR).
4. **Verifica**: CI e test.
5. **Rilascio**: artifact e deploy.
6. **Misura**: dashboard.

Ogni passaggio produce evidenze collegate: requisito → ticket → commit → pull request → build → test → release.
