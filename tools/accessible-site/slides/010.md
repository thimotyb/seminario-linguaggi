### Esempio di codice e schema del flusso

Codice JavaScript:

```
const numeri = [1, 4, 9, 16];
const raddoppia = x => x * 2;

const risultato = numeri.map(raddoppia);
// [2, 8, 18, 32]
```

Sotto il codice, uno schema in cinque passi mostra come la funzione `map` trasforma ogni valore dell’elenco senza modificarlo: 1 diventa 2, 4 diventa 8, 9 diventa 18, 16 diventa 32. Il risultato è l’elenco [2, 8, 18, 32].
