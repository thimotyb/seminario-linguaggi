# sostituisci
Linee guida ufficiali per lo sviluppo sicuro delle applicazioni nella Pubblica Amministrazione.

### Le quattro prospettive

| Prospettiva | Che cosa riguarda |
|---|---|
| Secure SDLC | azioni di sicurezza in tutte le fasi |
| Hardening | proteggere il software di base e il contesto |
| Secure coding | prevenire e individuare le vulnerabilità |
| Threat modeling | minacce, mitigazioni, Secure/Privacy by Design |

### Obiettivo

Disponibilità, integrità e riservatezza delle informazioni della PA.
