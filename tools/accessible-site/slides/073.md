# sostituisci
### Tre livelli di test in sequenza

Tre riquadri sovrapposti, con una freccia verso il basso tra l’uno e l’altro; ciascuno ha un titolo, un contesto e una descrizione:

| Livello | Contesto | Descrizione |
|---|---|---|
| 1. Unit test / test del developer | Task · locale | Verifica il comportamento del codice prima della Pull Request. |
| 2. Test automatici in CI | PR · build | La pipeline esegue i controlli: un esito negativo blocca il merge. |
| 3. Test di integrazione e validazione | develop → UAT → staging | Integrazione tecnica, accettazione degli stakeholder e verifica finale pre-produzione. |

**Se un test fallisce:** niente avanzamento; correggere il Task o aprire un Bug collegato, poi rieseguire il test.
