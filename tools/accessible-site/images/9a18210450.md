# alt
Slide "Threads - Locks/Monitors": scheda Threads di VisualVM con molti thread http-nio e fasi di attesa evidenziate con cerchi rossi.
# descrizione
Screenshot di una slide del corso Java Performance (pagina 112) che riproduce la scheda Threads di VisualVM per l'applicazione TicketServiceAPI-0.0.1-SNAPSHOT.jar. Mostra 125 thread attivi, di cui 121 daemon. La linea temporale elenca i thread http-nio-8080-exec-105 … 119 e per ciascuno una barra colorata nel tempo: verde per Running, viola Sleeping, giallo Wait, arancione Park, azzurro Monitor. Quattro zone, in cui compaiono tratti azzurri (thread bloccati su un monitor, cioè in attesa di un lock), sono cerchiate a mano in rosso. A destra, per ogni thread, il tempo in esecuzione e il totale (24.078 ms).
