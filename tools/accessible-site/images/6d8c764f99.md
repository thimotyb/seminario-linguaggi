# alt
Schema "Using a single custom API Gateway service": tre tipi di client passano da un unico API Gateway verso tre microservizi nel back end.
# descrizione
Diagramma Microsoft in inglese. A sinistra tre client: "Client mobile app" (telefono) e "Client SPA Web app" (JavaScript/Angular.js) inviano richieste in formato JSON; "Traditional Web app" (un browser) comunica in HTML con il "Client WebApp MVC" (contenitore ASP.NET Core MVC). Tutti questi client confluiscono, con frecce, in un unico riquadro "API Gateway" (contenitore, ASP.NET Core WebHost). Il gateway, a sua volta, instrada le richieste verso tre riquadri, "Microservice 1", "Microservice 2" e "Microservice 3", ciascuno una Web API in un container. Tutto tranne i client e il browser sta dentro un grande riquadro tratteggiato chiamato "Back end".
# testo
Using a single custom API Gateway service
Client mobile app —JSON→ API Gateway
Client SPA Web app (JavaScript/Angular.js) —JSON→ API Gateway
Traditional Web app (Browser) ←HTML→ Client WebApp MVC (ASP.NET Core MVC container) → API Gateway
API Gateway (container, ASP.NET Core WebHost) → Microservice 1 (Web API container); Microservice 2 (Web API container); Microservice 3 (Web API container)
Riquadro "Back end".
