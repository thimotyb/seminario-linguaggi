# descrizione
Screenshot delle impostazioni del progetto TitanoPortal in Azure DevOps, pagina "Service Hooks", con una finestra di dialogo "New service hooks subscription" sul passo "Action". A sinistra il menu Project Settings (General: Overview, Teams, Permissions, Notifications, Service hooks, Dashboards; Boards; Pipelines…). Nella finestra: azione "Post via HTTP", con la spiegazione che l'azione invia una rappresentazione JSON dell'evento all'URL indicato e il consiglio di usare solo endpoint HTTPS. Campi: URL (obbligatorio, vuoto, con segnale di errore), casella "Accept untrusted SSL certificates", "Basic authentication username" e "Basic authentication password" (facoltativi). In fondo i pulsanti Previous, Next, Test, Finish, Cancel (solo Previous e Cancel attivi).
