# alt
Parte finale dello schema sul service discovery: le istanze del Service A inviano heartbeat ai nodi di discovery e un'istanza guasta è barrata con una X rossa.
# descrizione
Ritaglio inferiore di una figura da un libro sui microservizi. In alto si intravede il fondo del riquadro verde con i tre nodi di discovery ("Service discovery node 1", "node 2", "node 3"). Sotto, un secondo riquadro verde chiamato "Service A" contiene quattro istanze del servizio (pile di server viola). Frecce verso l'alto collegano le istanze ai nodi di discovery: così le istanze si registrano. Quella più a destra ha una grande X rossa, cioè è guasta, e il suo collegamento tratteggiato è etichettato "Heartbeat": il segnale periodico che, se manca, fa considerare l'istanza non disponibile. A sinistra la didascalia numero 2.
