# alt
Schema dell'architettura Docker: sotto, hardware e sistema operativo; sopra, la parte utente con Docker CLI e daemon e tre container isolati.
# descrizione
Schema a strati. In basso l'hardware: riquadri "CPU", "Memory" e "IO" (che comprende "Network interface", "Persistent storage" e "Devices"). Sopra l'hardware, a tutta larghezza, il riquadro "Operating system". Sopra il sistema operativo la fascia "User space": a sinistra un'area verde con "Command line", che invia comandi con una freccia a "Docker CLI", il quale a sua volta comunica con "Docker daemon". A destra tre colonne affiancate, ognuna uno spazio isolato che condivide lo stesso sistema operativo: "Container space A" con "Web server", "Container space B" con "Hello World", "Container space C" con "Database".
# testo
User space: Command line → Docker CLI → Docker daemon
Container space A: Web server
Container space B: Hello World
Container space C: Database
Operating system
CPU; Memory; IO (Network interface, Persistent storage, Devices)
