# descrizione
Screenshot del sito "Can I use" (caniuse.com) aggiornato al 5 marzo 2026, con in alto il menu (Home, News, Compare browsers, About) e il campo di ricerca "Can I use ... ?". Il titolo della pagina è "CSS Grid Layout (level 1)". Un'etichetta "Baseline" segnala che la funzionalità è "Widely available across major browsers" (ampiamente disponibile nei principali browser). A destra i dati di utilizzo globale: 96,65% di supporto senza prefisso, più 0,24% parziale, per un totale del 96,88%. Sotto la descrizione c'è la tabella di compatibilità per browser: sulle colonne Chrome, Edge, Safari, Firefox, Opera, IE, Chrome per Android, Safari su iOS, Samsung Internet, Opera Mini, Opera Mobile, UC Browser, Android Browser, Firefox per Android; le celle verdi indicano le versioni che supportano la funzionalità (ad esempio Chrome dalla 57), le celle rosse quelle che non la supportano (ad esempio Chrome 4-28, IE 6-9), quelle giallo scuro il supporto parziale (ad esempio Edge 12-15, IE 10). La parte visibile della tabella si interrompe in basso.
