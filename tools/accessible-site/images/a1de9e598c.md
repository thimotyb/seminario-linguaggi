Schermata di Microsoft Threat Modeling Tool: diagramma con utente, web server e archivio dati, e tabella con nove minacce generate.
# descrizione
Screenshot di "New Threat Model* - Microsoft Threat Modeling Tool (Preview)". In alto il menu (File, Edit, View, Settings, Diagram, Reports, Help) e la barra degli strumenti. Nell'area di disegno "Diagram 1" un diagramma di flusso dei dati: a sinistra un'entità esterna quadrata "Human User", al centro un processo circolare "Web Server", a destra un archivio dati "Generic Data Store". Tra Human User e Web Server due frecce curve opposte, etichettate "Commands" (verso il server) e "Responses" (verso l'utente); tra Web Server e Generic Data Store due frecce etichettate "Configuration" e "Results". Sotto, il pannello "Threat List" con nove minacce generate automaticamente, tutte in rosso con stato "Not Started" e priorità "High". Il pannello "Threat Properties" è vuoto: "No threats are selected".
