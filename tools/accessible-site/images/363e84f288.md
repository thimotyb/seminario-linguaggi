# alt
Slide "Base profiling: VisualVM" con screenshot dell'IDE e della scheda Threads di VisualVM che mostra thread "zombie".
# descrizione
Screenshot di una slide del corso Java Performance (pagina 99). In alto a destra tre cartoni animati di zombie, a richiamare i "zombie thread". A sinistra, sotto il titolo, un link a VisualVM e un punto elenco con il link a un esempio su GitHub. Sotto, uno screenshot di un IDE Eclipse con il progetto "profile-threads-starter", il file Main.java aperto e la console con messaggi di log in rosso; una freccia rossa con la scritta "Main exits" indica la fine del metodo main e un cerchio rosso evidenzia il pulsante rosso di stop della console, ancora attivo. A destra, la scheda Threads di VisualVM per il processo main.Main: l'elenco dei thread con barre orizzontali nel tempo, quasi tutte verdi (running) per 109.910 ms, qualche barra gialla (wait) o arancione (park). Una freccia collega il testo esplicativo ai thread Thread-0, Thread-1, Thread-2 e Thread-3 sempre in esecuzione.
