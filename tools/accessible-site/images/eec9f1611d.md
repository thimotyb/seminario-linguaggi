# alt
Schermata di VisualVM, scheda Visual GC, che mostra memoria e garbage collection di un'applicazione Eclipse.
# descrizione
Screenshot della finestra di VisualVM 2.1.6 (pagina 79 del corso Java Performance, giugno 2023). Nella colonna sinistra c'è l'elenco delle applicazioni (Local: VisualVM ed Eclipse; Remote, VM Coredumps, JFR Snapshots, Snapshots). Nella scheda "Visual GC" del processo Eclipse si vedono tre pannelli. "Spaces": colonne verticali per Metaspace, Old ed Eden, più due riquadri S0 e S1, riempite in parte (Eden è riempita per circa un quinto, le altre quasi vuote). "Graphs": grafici temporali con i valori numerici indicati nell'etichetta. "Histogram": parametri di tenuring e quindici caselle numerate da 0 a 15, di cui solo la casella 1 è piena.
